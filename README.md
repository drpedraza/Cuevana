# 🎬 Cuevana

Este proyecto es una aplicación web desarrollada como práctica integradora. Permite la gestión de películas, personas y repartos utilizando un backend desarrollado en Django (API REST) y un frontend hecho con React y TypeScript. La aplicación permite realizar operaciones CRUD, autenticación básica y navegación entre vistas detalladas de las entidades.

## 📌 Funcionalidades

- 🔐 Autenticación de usuarios
- 🎥 CRUD de películas
- 👤 CRUD de personas
- 🎭 CRUD de repartos (asociación entre películas y personas)
- 🔎 Visualización de detalles de películas, personas y repartos
- 🧭 Navegación por distintas secciones del sitio

## 🛠 Tecnologías

### Backend
- Python
- Django
- Django REST Framework

### Frontend
- React
- TypeScript
- React Router
- Axios
- Redux Toolkit
